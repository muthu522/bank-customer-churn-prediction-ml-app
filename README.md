# Bank Customer Churn Prediction ML App

Project Overview

This project is an end-to-end Machine Learning application that predicts whether a bank customer is likely to leave (churn) or stay with the bank.

It combines data preprocessing, feature engineering, model building, and deployment using an interactive web app.

# Features
        📊 Data preprocessing and cleaning
        🔍 Exploratory Data Analysis (EDA)
        🤖 Machine Learning model (Classification)
        📈 Feature importance visualization
        🌐 Interactive web application using Streamlit
        ⚡ Real-time customer churn prediction
        
# Tech Stack
           Language: Python
           Libraries: Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
           Deployment: Streamlit
           Version Control: Git & GitHub

# Input Features

The model uses the following inputs:
      1 Credit Score
      2 Geography (France, Germany, Spain, India*)
      3 Gender
      4 Age
      5 Tenure
      6 Balance
      7 Number of Products
      8 Has Credit Card
      9 Is Active Member
      10 Estimated Salary

# Model Workflow
      1 Data Collection
      2 Data Preprocessing
      3 Feature Engineering
      4 Model Training (Random Forest / Logistic Regression)
      5 Model Evaluation
      6 Deployment using Streamlit
